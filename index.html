팀 구성 및 역할

① 기획 (입찰팀)

제안요청서(RFP)를 분석해 참가 조건을 검토하고 제안서를 구조화·통합하는 역할을 담당한다. 다만 제안서 안의 창작 콘텐츠(핵심 컨셉·스토리·연출안)는 입찰팀 단독 결정이 아니라 연출(감독)과 공동으로 만든다.

  • 제안요청서 분석 — 요구사항을 정리해 입찰 조건과 평가항목, 참가 자격을 검토한다.
  • 경쟁사 및 시장조사 — 경쟁사 사례와 시장 트렌드를 조사해 제안 전략에 반영한다.
  • 제안서 구조화 및 통합 — 제안서 목차와 사업전략을 설계해 사업이해도부터 운영계획까지 문서를 통합 작성하며, 핵심 컨셉과 연출안은 연출(감독)과 공동 개발한 뒤 제안서 형식에 맞게 구조화한다.
  • 입찰 일정 및 인력계획 — 제안 단계 일정을 관리하고 필요 인력과 예산 계획을 정리한다.
  • 경쟁 프레젠테이션 대응 — 발표 자료를 준비하고 리허설을 진행하며, 연출팀이 동반할 수 있다.
  • 입찰 결과 관리 — 결과를 트래킹해 피드백을 정리하고 탈락 사유를 분석한다.

② 연출(감독)

클라이언트 요구사항을 분석해 기획 방향을 설계하고 스토리보드·프레젠테이션으로 구체화하는 역할을 담당한다. 감독은 별도 팀이 아니라 연출 내에서 방향성을 최종 결정하고 완성본의 품질을 책임지는 최종 승인 역할로 기능한다.

연출 — 기획/구체화 파트

  • 기획 및 제안 — 프로젝트 컨셉을 정리하고 클라이언트 요구사항을 분석하며 경쟁사 유사사례와 트렌드를 리서치한다.
  • 콘티/스토리보드 — 씬별 구성과 카메라 앵글, 타이밍을 결정하고 시퀀스 연결을 검토한다.
  • 클라이언트 프레젠테이션 — 제안 내용을 시각화해 발표 슬라이드를 구성하고 예상 질문 정리와 리허설을 진행한다.
  • 레퍼런스/무드보드 — 비주얼 톤과 유사 사례를 조사해 스타일 방향을 제시하고 레퍼런스를 아카이빙한다.
  • 현장 진행 계획안 — 촬영·설치 일정 초안과 현장 동선을 설계하고 리스크 요소를 사전 점검한다.
  • 내부 커뮤니케이션 — 킥오프 자료를 준비하고 팀 내 방향을 공유하며 수정사항 반영본을 관리한다.

연출 — 감독(최종 승인) 파트

  • 컨셉 최종 컨펌 — 기획안을 검토해 방향성을 최종 결정하고 팀 제안에 피드백을 준다.
  • 룩앤필 가이드 — 색감과 톤 기준을 설정하고 비주얼 레퍼런스를 확정해 스타일 일관성을 점검한다.
  • 크리에이티브 디렉션 문서 — 창작 방향성을 문서화해 팀 공유용 가이드와 프로젝트별 디렉션 노트를 작성한다.
  • 결과물 최종 승인 — 완성본을 검수해 수정을 지시하거나 출고를 승인한다.
  • 현장 디렉팅 — 설치 현장을 최종 확인하고 실시간으로 수정을 지시한다.
  • 신기술 검토 — 신규 표현 기법을 리서치해 프로젝트 적용 가능성을 판단한다.

③ 피디

프로젝트 전체 일정을 설계하고 외주처를 관리하며, 클라이언트 보고와 현장 진행까지 프로젝트 전반을 조율하는 역할을 담당한다.

  • 일정 관리 — 전체 타임라인과 마일스톤을 설계하고 진행상황을 트래킹하며 지연 리스크에 대응한다.
  • 외주처 관리 및 소통 — 외주처를 발굴해 업무 범위를 조율하고 진행상황과 외주처 데이터베이스를 관리한다.
  • 외주 발주 계약 — 계약서를 작성해 업무 범위와 산출물 기준을 명시한다.
  • 클라이언트 보고 — 진행상황과 이슈를 정리해 보고용 문서와 회의록을 작성한다.
  • 현장 진행 조율 — 현장 인력을 배치하고 일정을 조율하며 돌발상황에 대응한다.
  • 내부 프로세스 관리 — 커뮤니케이션 채널을 관리하고 프로젝트와 문서 버전을 아카이빙한다.

④ 제작 (AI팀)

프롬프트 작성부터 이미지·영상 생성, 3D 변환용 에셋 제작, 후처리까지 AI 기반 제작물을 담당한다.

  • AI 생성 이미지 — 프롬프트를 작성해 이미지를 생성하고 결과물을 선별·보정한다.
  • AI 생성 영상 — 영상 프롬프트를 구조화해 영상을 생성하고 결과물을 검수한다.
  • 프롬프트 엔지니어링 — 프롬프트 구조를 정리해 재사용 템플릿화하고 라이브러리로 관리한다.
  • 3D 변환용 베이스 에셋 — 3D 변환에 적합한 이미지와 턴어라운드 이미지를 제작한다.
  • 업스케일·리터칭 — 해상도를 업스케일하고 디테일을 보정해 노이즈를 제거한다.
  • 2D 모션 그래픽 — 모션 그래픽을 제작하고 애니메이션 타이밍을 조정한다.

대시보드의 광역 담당 구분(디렉터풀/PD풀/AI팀)은 위 4개 팀을 다음처럼 묶은 것입니다 — 디렉터풀 = 연출(감독), PD풀 = 피디, AI팀 = AI팀. 입찰팀(기획)은 별도 트랙으로 사전제작 이전(입찰 진행 여부 결정) 단계에서 별도로 움직이며, 창작 콘텐츠 부분만 연출(감독)과 협업합니다.

콘텐츠 제작 파이프라인 — 파트별(기획 · AI · 2D · 3D)

일정 계산기와 동일하게, 콘텐츠 제작 과정 전체를 기획 · AI · 2D · 3D 4개 파트로 정리합니다. 원테이크·연속연출은 이 흐름 안에서 쓰이는 하나의 방식(예: 2D 파트의 프레임 이어붙임 방식)일 뿐, 별도의 메인 흐름이 아닙니다. 2D·3D 작업도 조직상 AI팀 소속이며, 각각 2D 작업자·3D 작업자가 담당합니다. 연출(감독)은 이 중 한 파트가 아니라, 기획부터 전달까지 전체 흐름을 관통하며 감수·승인하는 별도 트랙입니다 (아래 참고).
① 기획 → ② 스토리보드/콘티 제작 → ③ 본 제작 (AI · 2D · 3D 파트별) → ④ 최종 렌더링 → ⑤ 검수 → ⑥ 전달

기획 파트

기획→콘티/스토리보드

요구사항 분석·컨셉 설계 → 레퍼런스·무드보드 → 스토리보드·콘티(씬 구성, 카메라 워크) → 감독 컨펌

담당: 디렉터풀(연출·감독)

AI 파트

이미지 생성→영상 생성

프롬프트 구조화 → AI 이미지 생성(스토리보드 순서에 따른 에셋 이미지 포함) → AI 영상 생성 → 1차 검수

담당: AI팀(AI 작업자) — 에셋 이미지 작업도 AI 작업자가 담당하며, 감독은 필요시 보조로만 참여

세부 하위 파이프라인: 아래 "AI 활용 세부 파이프라인" 참고

2D 파트

합성→모션그래픽

AI 생성물 합성·편집 → 프레임/컷 연결 보정 → 모션그래픽 추가 (원테이크·연속연출의 경우 이 단계에서 프레임 이어붙임 보정 수행)

담당: AI팀(2D 작업자)

3D 파트

모델링→리깅→텍스처링→라이팅→렌더링→컴포지팅

3D 에셋 제작·리깅 → 텍스처·라이팅 세팅 → 렌더링 → 왜곡 보정 등 최종 합성

담당: AI팀(3D 작업자)

연출(감독) 트랙 — 전체 파트를 관통하는 감수·승인 라인

기획·AI·2D·3D처럼 하나의 구간에만 머무르지 않고, 기획부터 전달까지 전 구간에 걸쳐 확인·승인하는 병행 트랙입니다.

기획 단계

컨셉 정리·요구사항 분석, 레퍼런스/무드보드 조사, 콘티/스토리보드 작성, 룩앤필 가이드(색감·톤 기준) 확정

제작 진행 중 (AI·2D·3D 작업 동안)

각 파트의 중간 결과물이 컨셉과 일치하는지 확인하고 방향을 재확인·피드백 (파트마다 반복되는 확인 루프)

최종 승인 단계

전체 결과물을 검수해 수정 지시하거나 출고 승인

출력/설치 단계

현장 설치 결과를 최종 확인하고 실시간으로 수정 지시 (현장 디렉팅)

상시 병행 업무

크리에이티브 디렉션 문서화(팀 공유 가이드·프로젝트별 디렉션 노트), 신기술 검토, 클라이언트 프레젠테이션 대응

AI 활용 세부 파이프라인

1. AI 이미지 생성

레퍼런스·컨셉 브리프로 프롬프트를 구조화해 베이스 이미지를 생성, 결과물을 선별·보정

단계: 레퍼런스 수집 → 프롬프트 구조화(Zone 매핑, JSON) → 생성 → 검수 → 리터칭

툴: Higgsfield(Seedream), Midjourney, Gemini, GPT Image

2. AI 영상 생성

스토리보드 기반 시작·엔드 프레임을 지정해 영상 생성, 30초 이상은 이어붙임

단계: 프롬프트 구조화 → 프레임 지정 → 생성 → 검수 → 이어붙임·보정(30초 이상)

툴: Higgsfield(Seedance), Kling

3. AI 업스케일·리터칭

1차 생성 결과물의 해상도를 높이고 디테일 보정하는 후처리

단계: 1차 생성물 수집 → 업스케일 → 디테일 보정·노이즈 제거 → 색보정

툴: Topaz(Video AI, Photo AI), Adobe Firefly, Seedance 업스케일

4. AI-to-3D 변환

3D 변환 적합 이미지(정면·측면·후면 등) 제작 후 3D 메시로 변환, 리깅까지 이어짐

단계: 멀티뷰 이미지 제작 → Image-to-3D → 메시 검사 → 리토폴로지 → UV 재정리 → 텍스처 재투영 → Auto Rig → 스킨 웨이트 보정 → 모션 리타겟

담당: AI팀(이미지 → 3D 작업자가 리토폴로지·리깅) · 주의: AI 생성 3D는 최종 애셋이 아니라 블록아웃·베이스 메시로 간주

5. AI 보조 로토스코핑·합성 보정

AI로 임시 매트를 생성한 뒤 수동으로 정밀도를 보완하는 하이브리드 파이프라인

단계: 원본 Plate → AI Segmentation(임시 매트) → Garbage Matte → 수동 Core Matte → 헤어·모션블러 보완 → Edge Erode/Dilate → 최종 매트 Publish

주의: AI 출력은 최종 결과물이 아니라 로토 아티스트가 수정할 초기 매트로 취급

6. 프롬프트 엔지니어링 (공통 지원)

단계: Zone 매핑 설계 → JSON 구조화 → 네거티브 프롬프트 작성 → 템플릿화 → 라이브러리 관리
